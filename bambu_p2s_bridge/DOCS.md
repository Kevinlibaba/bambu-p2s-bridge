# Bambu P2S Bridge

## 开始之前

在打印机屏幕上：**设置 → 网络 → 局域网模式**，打开后再打开「开发者模式」，记下那页的 8 位访问码。

> 局域网模式下打印机不再连接 Bambu 云：Bambu Handy 的远程查看、云打印会用不了；
> Bambu Studio 仍可通过局域网打印。

## 安装与设置

1. 安装并启动本加载项。
2. 点「打开网页界面」（或浏览器打开 `http://<Home Assistant 的 IP>:8080/app/`）。
3. 跟着设置向导：选打印机（局域网里自动找，找不到就手填 IP 和序列号）→ 填访问码。
   向导会先真的连上打印机再保存，然后自动重启进入正常模式。
4. 最后一页有二维码，手机相机扫一下，App 打开就已登录。iPhone 上「分享 → 添加到主屏幕」后还能收推送。

配置、打印历史、MakerWorld 登录凭证都存在加载项自己的数据目录里，升级不会丢。

## 选项

- **port**（默认 8080）：网页界面与接口的端口。改了之后「打开网页界面」按钮仍指向 8080，
  请手动用新端口访问。

## 网络与端口

加载项使用宿主机网络（要收打印机的局域网广播）。占用的端口：

| 端口 | 用途 |
|---|---|
| 8080 | 网页界面与接口（可在选项里改） |
| 18555 | 摄像头实时画面（WebRTC，手机直连） |
| 11984、18554 | 摄像头转发服务，只在本机回环地址上 |

刻意避开了 go2rtc 默认的 1984 / 8554 / 8555 —— 装了 Frigate 的话它自带的 go2rtc 正占着那几个。

## 云切片

在 App 的「我的 → 设置 → 云切片」里一键下载 BambuStudio（约 219MB，占盘 540MB）。
**只支持 amd64**：BambuStudio 没有 ARM 的 Linux 版，树莓派上的 Home Assistant 用不了切片，
请在电脑上切好再上传。

## 从外网访问

最简单的是 Home Assistant 的 Tailscale 加载项：装好后用 tailnet 里的地址访问 8080 端口。
不要把 8080 直接映射到公网。
